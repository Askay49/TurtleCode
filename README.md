# Turtle Code — v0.10.4

Turtle Code — нативный редактор кода для Linux на C++ и Qt Widgets.
В основе редактора — собственный текстовый буфер Piece Tree и отрисовка видимой
части документа. Проект находится в активной разработке.

## Возможности

- Дерево проекта с созданием, копированием, переносом, переименованием и
  удалением файлов и папок, копированием полных и относительных путей.
- Редактирование нескольких документов, история отмены и восстановления,
  поиск и замена в файле и проекте.
- Синтаксическая подсветка Tree-sitter с установкой языковых грамматик из приложения.
- Подключение языковых серверов LSP: диагностика, автодополнение, переход к
  определению, переименование символов и форматирование при поддержке сервера.
- Git-панель с просмотром изменений, подготовкой индекса, фиксациями и
  сравнением файлов, поддержкой вложенных репозиториев.
- Встроенный терминал и отладка через адаптеры DAP.
- Темы Catppuccin Latte, Frappé, Macchiato и Mocha; настраиваемые темы, шрифты и сочетания клавиш, русский и английский интерфейс.
- Настройки проекта из `.editorconfig`: отступы, табуляция и правила сохранения.
- Vim-режим: Normal / Insert / Visual, движения, счётчики, `d/c/y`, текстовые
  объекты, регистры, повтор `.`, макросы, marks и история переходов,
  Visual Block / Replace, группировка Undo и строка `:` с интерпретатором Ex,
  диапазонами, цепочками команд, историей и подсказками. Поиск `/` и `?`,
  шаблоны Vim и замены `:s`, включая подтверждение; `:global`, `:normal`,
  операции строк, файлов и буферов. Команды `J/gJ`, смена регистра, `Ctrl+A/X`,
  отступы `=`, форматирование `gq` и переходы по изменениям. Включается в настройках.

Возможности LSP и отладки зависят от установленных серверов и адаптеров.
Поддержка конфигураций VS Code частичная; подробнее — в документации ниже.

## Дерево проекта и предпросмотр

В шапке дерева есть кнопки **Новый файл**, **Новая папка** и **Свернуть всё**.
Новый элемент создаётся в выбранной папке, рядом с выбранным файлом или
в корне проекта, если ничего не выбрано. **Свернуть всё** закрывает все
раскрытые папки вместе с корнем.

В **Настройки → Файлы и поиск** можно включить предпросмотр по одиночному
клику в дереве проекта. Двойной клик закрепляет открытый файл. Пока файл в
предпросмотре, его имя отображается курсивом, а при переключении на другой
файл временный буфер закрывается. В сплитах предпросмотр остаётся открытым,
пока его показывает хотя бы одна панель.

Вложенная настройка закрепляет файл при первой правке. Если она выключена,
при уходе с изменённого файла редактор предложит сохранить или отбросить правки
либо отменить переключение. Предпросмотр по умолчанию выключен.

В меню **Вид** и в палитре команд есть команда **Показать активный файл в
дереве проекта**. Она раскрывает родительские папки и выделяет файл, в том
числе на последующих страницах каталога. В **Настройки → Файлы и поиск** можно
включить автоматическое выделение при смене активного файла. Автосинхронизация
работает, когда открыта панель дерева, и учитывает её фильтры.

Там же можно включить **Компактные папки в дереве проекта**. Если после
применения фильтров в папке видна только одна вложенная папка, дерево объединяет
их в одну строку, например `src/core/text`. Корень проекта отображается
отдельно. Команды объединённой строки работают с последней папкой цепочки.

Команда **Поиск в этой папке** в контекстном меню папки открывает панель
поиска и замены. Поиск охватывает выбранную папку и её подпапки с учётом
фильтров проекта. Кнопка × рядом с именем папки или `Ctrl+Shift+F` возвращает
поиск по всей рабочей области.

**Открыть в файловом менеджере** открывает выбранную папку. **Новый терминал
здесь** запускает оболочку в этой папке в отдельной вкладке встроенного
терминала. Если выбран файл, обе команды используют его родительскую папку.

**Вид → Перейти в дерево проекта** (`Ctrl+Shift+E` по умолчанию) открывает
панель дерева и передаёт ей фокус. Команда доступна и в палитре.
`Enter` открывает выбранный файл в обычной вкладке и передаёт фокус редактору.
На папке `Enter` переключает её раскрытие. `F2` переименовывает выбранный
элемент дерева, а в редакторе вызывает переименование символа.
В Vim-режиме `j` и `k` перемещают выделение вниз и вверх, а `h` и `l`
сворачивают и раскрывают выбранную папку.

При фокусе дерева `Ctrl+C`, `Ctrl+X` и `Ctrl+V` копируют, вырезают и вставляют
файлы и папки. Те же действия доступны в контекстном меню, где **Дублировать**
создаёт копию рядом с исходным элементом. Вставка использует выбранную папку,
родительскую папку выбранного файла или корень проекта. При совпадении имени
**Сохранить оба** добавляет копии или перенесённому элементу свободное имя.
Для переноса мышью перетащите файл или папку на строку папки назначения.
Задержите указатель над свёрнутой папкой, чтобы раскрыть её. При перетаскивании
действует тот же диалог совпадения имён, что и при вставке. Оба способа переносят
элементы в пределах одной файловой системы и обновляют пути открытых файлов
и точек останова.

При фокусе дерева `Delete` перемещает выбранный файл или папку в системную
корзину. По умолчанию открывается подтверждение с фокусом на **Да**. Нажмите
`Enter`, чтобы продолжить, или `Esc`, чтобы отменить. Запрос можно отключить в
**Настройки → Файлы и поиск → Подтверждать перемещение в корзину**. В контекстном
меню есть **Переместить в корзину** и **Удалить безвозвратно…**. Для корня проекта
`Delete` и команда **Убрать папку из рабочей области** закрывают проект после
подтверждения и сохраняют папку и её содержимое на диске.

## Внешние изменения файлов

Открытые файлы без несохранённых правок автоматически обновляются с диска.
Позиция курсора и прокрутка сохраняются насколько возможно; история Undo
при загрузке внешней версии сбрасывается.

При конфликте с несохранёнными правками редактор предлагает загрузить версию
с диска или оставить свои правки. Во втором случае сохранение по-прежнему
запрашивает подтверждение перед перезаписью внешней версии. Если файл удалён
извне, текст остаётся во вкладке как несохранённая копия; его можно сохранить
заново. Внешнее переименование обрабатывается как удаление старого пути.

## Требования для сборки

- Linux.
- CMake 3.25 или новее.
- Компиляторы с поддержкой C++23 и C11.
- Qt 6.2.4 или новее: Core, Gui, Widgets, Network, Concurrent и Test.
- pkg-config и libgit2 1.1 или новее с заголовочными файлами.
- EditorConfig Core C с заголовочными файлами (`libeditorconfig-dev` в Ubuntu).
- SQLite 3 и PCRE2-16 с заголовочными файлами (`libsqlite3-dev`, `libpcre2-dev`).
- Tree-sitter runtime с заголовочными файлами. Требуется API ограничения времени
  разбора или progress callback; доступность проверяется CMake.
- Python 3.8 или новее для полного набора тестов.

Ninja нужен только для сборки через пресеты. Иконки, темы и исходники libvterm
включены в репозиторий вместе с лицензиями; загружать их отдельно не требуется.
Языковые грамматики Tree-sitter устанавливаются отдельно из редактора.

## Сборка и запуск

Выполните из корня проекта:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
./build/turtle-code
```

Можно сразу открыть каталог или файлы:

```sh
./build/turtle-code /path/to/project
./build/turtle-code /path/to/file.cpp /path/to/another.py
```

Если зависимости установлены вне стандартных каталогов, укажите путь к ним
через `CMAKE_PREFIX_PATH` при настройке CMake.

Для сборки без синтаксического backend Tree-sitter:

```sh
cmake -S . -B build-no-treesitter -DTURTLE_CODE_ENABLE_TREE_SITTER=OFF
cmake --build build-no-treesitter -j4
```

Обычная сборка не собирает и не запускает тесты. Дополнительные варианты сборки,
включая пресеты Ninja, описаны в [инструкции по сборке](docs/BUILDING.md).

## Установка в Linux

После публикации тега стабильная версия `Turtle_Code-x86_64.AppImage` появляется в
[GitHub Releases](https://github.com/Askay49/TurtleCode/releases).
Сборки ветки `main` доступны в разделе Artifacts успешных запусков
[GitHub Actions](https://github.com/Askay49/TurtleCode/actions/workflows/appimage.yml).
Подробнее — [сборка AppImage](docs/BUILDING.md#appimage-и-github-actions).

После сборки установите приложение для текущего пользователя:

```sh
cmake --install build --prefix "$HOME/.local"
```

Устанавливаются программа в `~/.local/bin`, ярлык в
`~/.local/share/applications`, SVG и PNG-иконки в
`~/.local/share/icons/hicolor`. Turtle Code появится в меню приложений и списке
«Открыть с помощью» для поддерживаемых текстовых типов файлов. Установка
не меняет приложение по умолчанию для этих файлов.

Каталог `~/.local/bin` должен быть в `PATH` графической сессии. Если его нет,
добавьте его в настройки окружения своего рабочего стола и войдите в систему
заново. Для запуска напрямую можно использовать `~/.local/bin/turtle-code`.

Если меню не обновилось сразу, выполните при наличии соответствующих утилит:

```sh
update-desktop-database "$HOME/.local/share/applications"
gtk-update-icon-cache --force --ignore-theme-index "$HOME/.local/share/icons/hicolor"
```

Установленная программа использует системные библиотеки Qt, libgit2 и
Tree-sitter из окружения сборки; эта установка не создаёт автономный пакет.

## Первоначальная настройка

- Откройте проект, передав путь к каталогу при запуске или выбрав его в приложении.
- Для подсветки установите нужные грамматики в разделе «Настройки → Настройки… → Языки и инструменты → Подсветка синтаксиса».
  Для их загрузки и сборки нужны Интернет, `tar` и C-компилятор (`cc`, `clang` или `gcc`).
- Для возможностей LSP установите соответствующий языковой сервер и настройте
  его профиль. Для C/C++ используется clangd; для точного анализа проекта
  ему может понадобиться `compile_commands.json`.
- Для отладки установите подходящий DAP-адаптер и создайте конфигурацию запуска.
  См. [настройку отладки](docs/DEBUGGING.md).

## Проверки

Собрать тесты и запустить обычный набор:

```sh
cmake --build build --target turtle-code-check -j4
```

Либо собрать и запустить отдельно:

```sh
cmake --build build --target turtle-code-tests -j4
ctest --test-dir build --output-on-failure -LE memory
```

Для оконных тестов требуется доступная графическая сессия или настроенная
тестовая среда Qt. Тесты памяти включаются отдельно и описаны
в [MEMORY_TESTS.md](docs/MEMORY_TESTS.md).
