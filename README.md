# Turtle Code — v0.9.8

Turtle Code — нативный редактор кода для Linux на C++ и Qt Widgets.
В основе редактора — собственный текстовый буфер Piece Tree и отрисовка видимой
части документа. Проект находится в активной разработке.

## Возможности

- Дерево проекта с созданием, переименованием и удалением файлов и папок,
  копированием полных и относительных путей.
- Редактирование нескольких документов, история отмены и восстановления,
  поиск и замена в файле и проекте.
- Синтаксическая подсветка Tree-sitter с установкой языковых грамматик из приложения.
- Подключение языковых серверов LSP: диагностика, автодополнение, переход к
  определению, переименование символов и форматирование при поддержке сервера.
- Git-панель с просмотром изменений, подготовкой индекса, фиксациями и
  сравнением файлов, поддержкой вложенных репозиториев.
- Встроенный терминал и отладка через адаптеры DAP.
- Настраиваемые темы, шрифты и сочетания клавиш, русский и английский интерфейс.

Возможности LSP и отладки зависят от установленных серверов и адаптеров.
Поддержка конфигураций VS Code частичная; подробнее — в документации ниже.

## Внешние изменения файлов

Открытые файлы без несохранённых правок автоматически обновляются с диска.
Позиция курсора и прокрутка сохраняются насколько возможно; история Undo
при загрузке внешней версии сбрасывается.

При конфликте с несохранёнными правками редактор предлагает загрузить версию
с диска или оставить свои правки. Во втором случае сохранение по-прежнему
запрашивает подтверждение перед перезаписью внешней версии. Если файл удалён
извне, текст остаётся во вкладке как несохранённая копия; его можно сохранить
заново. Внешнее переименование обрабатывается как удаление старого пути.

## Требования для сборки

- Linux.
- CMake 3.25 или новее.
- Компиляторы с поддержкой C++23 и C11.
- Qt 6.2.4 или новее: Core, Gui, Widgets, Network, Concurrent и Test.
- pkg-config и libgit2 1.1 или новее с заголовочными файлами.
- Tree-sitter runtime с заголовочными файлами. Требуется API ограничения времени
  разбора или progress callback; доступность проверяется CMake.
- Python 3.8 или новее для полного набора тестов.

Ninja нужен только для сборки через пресеты. Иконки, темы и исходники libvterm
включены в репозиторий вместе с лицензиями; загружать их отдельно не требуется.
Языковые грамматики Tree-sitter устанавливаются отдельно из редактора.

## Сборка и запуск

Выполните из корня проекта:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
./build/turtle-code
```

Можно сразу открыть каталог или файлы:

```sh
./build/turtle-code /path/to/project
./build/turtle-code /path/to/file.cpp /path/to/another.py
```

Если зависимости установлены вне стандартных каталогов, укажите путь к ним
через `CMAKE_PREFIX_PATH` при настройке CMake.

Для сборки без синтаксического backend Tree-sitter:

```sh
cmake -S . -B build-no-treesitter -DTURTLE_CODE_ENABLE_TREE_SITTER=OFF
cmake --build build-no-treesitter -j4
```

Обычная сборка не собирает и не запускает тесты. Дополнительные варианты сборки,
включая пресеты Ninja, описаны в [инструкции по сборке](docs/BUILDING.md).

## Установка в Linux

Готовый `Turtle_Code-x86_64.AppImage` автоматически собирается в
[GitHub Actions](https://github.com/Askay49/TurtleCode/actions/workflows/appimage.yml).
Откройте успешный запуск и скачайте пакет из раздела Artifacts.
Подробнее — [сборка AppImage](docs/BUILDING.md#appimage-и-github-actions).

После сборки установите приложение для текущего пользователя:

```sh
cmake --install build --prefix "$HOME/.local"
```

Устанавливаются программа в `~/.local/bin`, ярлык в
`~/.local/share/applications`, SVG и PNG-иконки в
`~/.local/share/icons/hicolor`. Turtle Code появится в меню приложений и списке
«Открыть с помощью» для поддерживаемых текстовых типов файлов. Установка
не меняет приложение по умолчанию для этих файлов.

Каталог `~/.local/bin` должен быть в `PATH` графической сессии. Если его нет,
добавьте его в настройки окружения своего рабочего стола и войдите в систему
заново. Для запуска напрямую можно использовать `~/.local/bin/turtle-code`.

Если меню не обновилось сразу, выполните при наличии соответствующих утилит:

```sh
update-desktop-database "$HOME/.local/share/applications"
gtk-update-icon-cache --force --ignore-theme-index "$HOME/.local/share/icons/hicolor"
```

Установленная программа использует системные библиотеки Qt, libgit2 и
Tree-sitter из окружения сборки; эта установка не создаёт автономный пакет.

## Первоначальная настройка

- Откройте проект, передав путь к каталогу при запуске или выбрав его в приложении.
- Для подсветки установите нужные грамматики в разделе «Настройки → Языки».
  Для их загрузки и сборки нужны Интернет, `tar` и C-компилятор (`cc`, `clang` или `gcc`).
- Для возможностей LSP установите соответствующий языковой сервер и настройте
  его профиль. Для C/C++ используется clangd; для точного анализа проекта
  ему может понадобиться `compile_commands.json`.
- Для отладки установите подходящий DAP-адаптер и создайте конфигурацию запуска.
  См. [настройку отладки](docs/DEBUGGING.md).

## Проверки

Собрать тесты и запустить обычный набор:

```sh
cmake --build build --target turtle-code-check -j4
```

Либо собрать и запустить отдельно:

```sh
cmake --build build --target turtle-code-tests -j4
ctest --test-dir build --output-on-failure -LE memory
```

Для оконных тестов требуется доступная графическая сессия или настроенная
тестовая среда Qt. Тесты памяти включаются отдельно и описаны
в [MEMORY_TESTS.md](docs/MEMORY_TESTS.md).
